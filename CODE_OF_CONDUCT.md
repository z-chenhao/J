# Code of conduct

J is built through open technical disagreement, careful evidence, and respect
for the people doing the work.

## Expected behavior

- Discuss ideas and code without attacking people.
- State assumptions, evidence, and tradeoffs clearly.
- Welcome questions and corrections from contributors of every experience
  level.
- Respect privacy, credentials, unpublished work, and repository boundaries.
- Accept maintainers' decisions about project scope even when proposing a
  different direction.

## Unacceptable behavior

- Harassment, threats, discrimination, or sexualized attention.
- Personal insults, deliberate intimidation, or sustained disruption.
- Publishing another person's private information without permission.
- Using project spaces for spam or unrelated promotion.

## Enforcement

Maintainers may edit or remove comments, reject contributions, lock
conversations, or restrict participation when behavior conflicts with this
code. Enforcement decisions should be proportionate and should protect the
people affected.

For conduct that can be discussed publicly, open a repository issue with only
the minimum necessary context. For threats, private-information exposure, or
other sensitive abuse on GitHub, use
[GitHub's private abuse-reporting flow](https://support.github.com/contact/report-abuse)
instead of publishing details in this repository.
